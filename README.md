# MATLAB-Weather-Visualization-System
A program built with MATLAB designed to create visualizations using weather data from https://www.weatherstats.ca/. This program is designed to take the information from the "Climate Hourly" section (highlighted below) and visualize certain data (such as temperature, pressure, humidity and speed). The data is shown in a bar graph highlighting the minimum, maximum and average temperatures as well as a scatter plot showing the same values for every day in the date set.
